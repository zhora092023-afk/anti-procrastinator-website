# anti-procrastinator.com — запуск сайта

1. Загрузите содержимое папки `site` на хостинг (GitHub Pages / Timeweb / Beget / Netlify).
2. Счётчик Яндекс Метрики №114655816 уже встроен во все страницы (перед </body>).
3. Веб-версия CutTails: в файле `js/main.js` укажите реальный URL в `CONFIG.demoUrl` —
   после этого кнопка «Попробовать демо» откроет приложение в модальном окне (iframe).
4. Тест передаёт тип пользователя в демо через параметры: ?type=perfectionist&source=site-quiz
5. Добавление нового языка: скопируйте папку `ru` → `de`, переведите тексты,
   добавьте hreflang-ссылки в <head> всех страниц, строку в `sitemap.xml` и пункт в переключатель языков.

Проверка локально: `python -m http.server 8000` → http://localhost:8000
