# Anti-Procrastinator — сайт v4

## Что нового в v4
- Возвращён весь контент главной: 4 научные статьи, 4 типа прокрастинаторов, 6 методов, курьёзы, тест, FAQ.
- Счётчик Яндекс Метрики №114655816 на всех страницах (корневая, /ru/, /en/).
- Тест передаёт тип в демо: CONFIG.demoUrl + '?type=…&source=site-quiz'.

## Ширина страницы
Контейнер: max-width 1100px, центрирован — так задумано (читабельность строк). Изменить: в css/styles.css строка `.container{max-width:1100px;...}` — поставьте, например, 1300px или 100% без ограничений.

## Локальный просмотр
- Быстро: двойной клик по ru/index.html или en/index.html.
- Правильно: `python -m http.server 8000` → http://localhost:8000

## Публикация
GitHub Pages / Netlify / Timeweb: загрузите содержимое папки site.

## Добавить язык
1. locales/<lang>.json — по образцу существующих.
2. Скопируйте en/index.html → <lang>/index.html, переведите тексты, lang="de", hreflang.
3. Добавьте строку в sitemap.xml и ссылку в переключатель языков.
