# Anti-Procrastinator — стартовый мультиязычный сайт

Готовый статический шаблон: работает на любом хостинге без сборки (GitHub Pages, Netlify, Vercel, обычный shared-хостинг).

## Структура
- `index.html` — авто-редирект по языку браузера (en/ru) + fallback-ссылки
- `en/index.html`, `ru/index.html` — отдельные языковые версии (правильные URL для SEO)
- `locales/en.json`, `locales/ru.json` — весь контент в виде ключей; новые языки = новые файлы
- `js/main.js` — тест «какой вы прокрастинатор», демо-виджет CutTails
- `css/style.css` — оформление (тёмная тема, адаптив)
- `sitemap.xml` — уже с hreflang для en и ru
- `robots.txt`

## Что вставить перед публикацией
1. В `js/main.js` → `CONFIG.demoUrl`: URL веб-версии CutTails (PWA/демо-страница).
   Пока не задан, виджет покажет заглушку с подсказкой.
2. Страницу политики конфиденциальности (заглушка уже стоит в футере).
3. Мета-теги можно расширить (OG-картинки, JSON-LD FAQPage — желательные следующие шаги).

## Как добавить новый язык (например, немецкий)
1. Создайте `locales/de.json` по образцу `en.json` (те же ключи).
2. Скопируйте `en/index.html` → `de/index.html`, замените видимый текст и `lang="de"`,
   hreflang-блоки и ссылки переключателя языков.
3. Добавьте `/de/` в `sitemap.xml` (с hreflang для всех языков) и ссылку в переключатель.

## Публикация за 5 минут (Netlify)
1. Зарегистрируйтесь на netlify.com → Drag & drop папки `site` → сайт онлайн на поддомене.
2. Domain settings → Add custom domain → `anti-procrastinator.com`.
3. У регистратора домена укажите DNS-записи, которые предложит Netlify (обычно CNAME/A).
4. HTTPS включается автоматически.
