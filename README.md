# Anti-Procrastinator — сайт «под ключ»

Статический многоязычный сайт (RU/EN) с тестом на тип прокрастинации
и демо-виджетом PWA-приложения CutTails.

## Структура
- `index.html` — корень: редирект на язык браузера (с fallback-ссылками)
- `ru/index.html`, `en/index.html` — полные языковые версии (весь контент статический, SEO-готовый)
- `css/style.css` — стили
- `js/main.js` — тест, демо-модалка, мелочи

## Что сделать перед публикацией
1. В `js/main.js` укажите `CONFIG.demoUrl` — URL PWA CutTails (лучше поддомен `app.`).
2. На стороне CutTails разрешите встраивание:
   `Content-Security-Policy: frame-ancestors 'self' https://anti-procrastinator.com`
   (и НЕ отправляйте `X-Frame-Options: DENY/SAMEORIGIN`).
3. В демо-режиме CutTails используйте гостевой вход без регистрации и сохраняйте прогресс в localStorage.

## Добавление нового языка (пример: немецкий)
1. Скопируйте `en/index.html` → `de/index.html`, переведите тексты, поменяйте `lang="de"` и hreflang.
2. Добавьте страницу в `sitemap.xml` и ссылку в переключатель языков в шапках.

## Локальный просмотр
- Просто открыть `ru/index.html` двойным кликом — уже работает (контент статический).
- Или полноценный сервер: `python -m http.server 8000` → http://localhost:8000

## Публикация
- Netlify: перетащить папку в панель.
- GitHub Pages: репозиторий → Settings → Pages → ветка main / root.
- Российский хостинг (Timeweb Cloud, Beget): загрузить файлы в каталог сайта.

## Проверено локально
Тест, переключение языков и модалка работают без сети и без fetch —
все тексты зашиты в HTML, поэтому сайт открывается и с файловой системы.
